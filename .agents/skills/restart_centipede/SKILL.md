---
name: Restart Centipede
description: Restart the Centipede board with the Firmware using the restart.expect script.
---

When asked to "Restart the Centipede board with the Firmware", execute the following command:

```bash
cd v1/firmware && ./restart.expect
```

Note: This reboots the firmware and takes up to 15 seconds to run. Allow it sufficient time to complete.
