---
name: Using git
description: Guidelines and constraints for using git in this repository.
---

When interacting with git in this repository, you MUST follow these constraints:

1. You may examine the `work` branch using git commands (e.g., `git status`, `git diff`, `git log`).
2. Do NOT commit to the `work` branch unless the user explicitly asks you to or you have asked for and received permission from the user.
3. NEVER commit to any branches that do not start with the word `work`.
