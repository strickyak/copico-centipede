# v0: CocoFest demo 2026

This /v0/ is the version demonstrated at CocoFest in late April 2026.

It is designed for a coco2 with 16K RAM and Extende Color Basic.

It does the following:

* The firmware increases the amount of RAM seen by the Coco2 to 64K (using SLENB)
* The firmware acts as an 8K Disk Basic ROM (at addresses $C000-$DFFF)
* The firmware acts as a floppy drive, good enough for Disk Basic
* The tethered program (on the PC connected by USB cable) acts as a virtual VDG, exporting the screen image to a web browser at http://localhost:8080/

On a coco2 with 16K RAM builtin, when we increase the RAM to 64K using SLENB,
the VDG chip is still using the 16K builtin RAM.   That RAM gets corrupted by
memory writes above 16K, because the RAM Write is enabled due to partial
decoding of the address space.

The end result is that the VDG hardware will display pages with corruptions.
But the image on the web browser, generated by the Virtual VDG in the tethered program,
will be correct.
